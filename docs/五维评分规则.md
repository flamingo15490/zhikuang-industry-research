# 五维评分规则 2.0

本版本是可解释的研究观察规则，阈值和权重均为研究假设，未经过收益回测、预测能力验证或独立评级验证。分数用于展示输入在这组规则中的位置，不代表买卖建议、收益概率、违约概率或公允价值。更高的分数不保证未来表现更好。

## 接口与数据责任

`scoring.score_observation(raw: dict) -> dict` 是纯函数，不联网、不读缓存、不填补缺失值、不按板块中位数归一化，也不负责时间对齐。相同输入生成相同输出，不修改输入。`version` 固定为 `2.0`。

输入指标如下；百分率一律以百分数输入，例如10%传入 `10.0`，不是 `0.1`。金额仅用于技术指标价格水平，没有绝对资金金额评分。

| 键 | 输入含义与单位 | 使用维度 |
|---|---|---|
| `roe` | 同报告期ROE，% | 基本面 |
| `growth` | 净利润同比增长率，% | 基本面、安全度 |
| `pe` | PE(TTM)，倍 | 估值观察 |
| `ma5`, `ma20`, `ma60` | 同一价格序列的5/20/60日均价，元 | 技术面 |
| `dif`, `dea` | 同一序列的MACD DIF与DEA，元 | 技术面 |
| `rsi` | RSI，0至100指数点 | 技术面 |
| `return20` | 最近价格相对20个交易日前价格的收益率，% | 技术面 |
| `flow_ratio_pct` | 同五个交易日主力净流入合计÷成交额合计×100，% | 资金面 |
| `debt` | 同报告期资产负债率，% | 安全度 |
| `current` | 同报告期流动比率，倍 | 安全度 |

采集层负责核对来源、报告期、公告时间、交易日、复权口径、行情有效性和足够的历史长度。ROE、增长率、债率和流动比率应使用同一有效财务报告期，禁止将不同报告期混为同期观测。净利润增长的比较基期为亏损或零利润时，采集层必须传入 `growth=None`，不能把亏损收窄的比例当作常规盈利增长。评分函数只有增长率值，无法自行核验基期利润。

资金比率必须先求五日净流入合计和同五日成交额合计，再相除，不能用五个每日比率的简单平均。双方必须使用相同币种、金额单位和交易日；分母非正、日期不齐或记录缺失时传入 `None`。净流入定义依赖供应商，应附来源与口径。同比缩放分子分母不会改变分数，也不会天然奖励大市值公司。

仅接受有限实数，布尔值、数值字符串、NaN和正负无穷均记为无效。缺键与 `None` 记为缺失。均线必须大于0，RSI必须在[0,100]内，流动比率与债率不能为负，20日收益率不能小于-100%。债率大于100%仍有效，可能反映资不抵债；流动比率为0也有效。未知键不参与评分。传入非字典会抛出 `TypeError`。

## 缺失、覆盖率与综合分

每一维的所有必需指标都有效时才能出分。即使其余技术指标可用，缺失一个均线或RSI也会使整个技术面为缺失，不保留50分或部分加分。

| `status` | 含义 | 维度分数 |
|---|---|---|
| `complete` | 所有必需指标有效且规则适用 | 有限分数 |
| `missing` | 至少一项输入缺失、类型错误或超出有效域 | `None` |
| `not_applicable` | 目前用于有效数值PE<=0，正PE分档不适用 | `None` |

`missing` 列出不可用输入的键；非正PE是有效但不适用的观测，因此其 `missing` 为空，原始PE数值保留。每项指标的 `invalid_reason` 为 `missing`、`invalid_type`、`nonfinite`、`invalid_domain` 或 `None`。无法评分的指标标准化为 `value=None`，不把NaN传播到JSON。

`coverage` = 完整维度数÷5，不是字段完整率；不适用也不计完整。五维全部 `complete` 时，`eligible=True`，`composite` 为五个维度分数的等权算术平均，保留6位小数。否则 `eligible=False`、`composite=None`，不能参与综合排名。禁止对剩余维度重新分配权重，也不能把缺失填0。

相同综合分就是同分，评分引擎不产生排名或破同分键。排名层应并列处理同分，且仅比较相同版本、有效采集批次和明确可比范围的完整观测。历史1.x缓存不能与2.0混用。

## 基本面

基本面 = ROE分档分×70% + 净利润增长分档分×30%。采用绝对ROE分档，避免板块中位数为零或负数时除法改变经济方向。

| ROE（%） | 分档分 |
|---|---:|
| <0 | 0 |
| =0 | 20 |
| (0,5) | 40 |
| [5,10) | 60 |
| [10,15) | 80 |
| >=15 | 100 |

| 净利润增长率（%） | 分档分 |
|---|---:|
| <-20 | 10 |
| [-20,0) | 30 |
| =0 | 50 |
| (0,20) | 70 |
| >=20 | 90 |

增长为0属于中性档，不按负增长扣分。负ROE明确处于最低ROE档；增长基期是否可比必须由采集层验证。由于增长最高90分，该维理论最高97分，没有强行拉满到100。

## 估值观察

输出兼容键仍为 `估值`，维度 `label` 为 `估值观察`。PE<=0返回不适用，不因数值低而奖励亏损或零利润企业。

| 正PE(TTM)，倍 | 分数 |
|---|---:|
| (0,10) | 90 |
| [10,15) | 75 |
| [15,20) | 60 |
| [20,30) | 45 |
| >=30 | 30 |

这些是正PE绝对分档，不是历史分位。周期行业景气高点利润可能推低PE，景气低点利润可能推高PE；较高观察分不能表述为“便宜”“低估”或合理价格。周期归一化利润、PB与ROE交叉检查仍待实现，本版本不声称已完成。

## 技术面

技术面 = 50 + 均线排列贡献 + MACD比较贡献 + RSI区间贡献 + 20日收益方向贡献。七个输入均为必需。内部规则包含趋势与区间观察假设，未验证择时能力。

| 组件 | 条件 | 加减分 |
|---|---|---:|
| 均线 | MA5>MA20>MA60 | +15 |
| 均线 | MA5<MA20<MA60 | -15 |
| 均线 | 其余排列，含任意相等 | 0 |
| MACD | DIF>DEA / DIF<DEA / 相等 | +10 / -10 / 0 |
| RSI | 40<RSI<60 | +5 |
| RSI | RSI<30或RSI>70 | -5 |
| RSI | 其余，含30、40、60、70边界 | 0 |
| 20日收益 | >0% / <0% / =0% | +10 / -10 / 0 |

相等比较中性，零收益不自动加分。RSI极端区间的负贡献表示本规则对极端状态的保守处理，不推断反转。技术面理论范围为10至90分。

输出 `base_score=50`。指标逐项输出 `delta`；均线整组贡献记在 `ma5`，`ma20`和`ma60`为0；MACD整组贡献记在 `dif`，`dea`为0。关联指标的规则文字同时说明整组只计一次，前端可据此展示并避免重复累加。

## 资金面

资金面 = `min(90, max(10, 50 + 4 × flow_ratio_pct))`。

0%对应50分，+2%对应58分，-2%对应42分；达到+10%封顶90分，达到-10%封底10分。边界连续，没有把零流量判为流出。封顶封底用于限制单期异常比率影响，不是经验证的市场阈值。不能用净流入亿元值替代比率。

## 安全度

安全度 = 债率分档分×40% + 增长分档分×30% + 流动比率分档分×30%。增长规则与基本面一致，因此增长在两维重复使用是明确的设计假设，并非独立证据；五维综合中增长对应12%的显式权重。

| 资产负债率（%） | 分档分 |
|---|---:|
| [0,40) | 90 |
| [40,60] | 70 |
| (60,70] | 50 |
| >70 | 20 |

| 流动比率，倍 | 分档分 |
|---|---:|
| [0,1) | 20 |
| =1 | 50 |
| (1,2) | 70 |
| >=2 | 90 |

该维理论最高90分，只反映这三个财务观察项，不是综合经营风险或信用评级。少数股东权益比例与披露标签不参与安全度；披露完整性、来源校验状态应在产品中独立展示，不能因披露颗粒度差直接扣经营风险分。

## 可核对示例

ROE=10%、增长=0%、PE=15倍、三条均线均为10元、DIF=DEA=0、RSI=40、20日收益=0%、资金比率=0%、债率=60%、流动比率=1时：基本面71、估值观察60、技术面50、资金面50、安全度58，综合57.8，覆盖率100%。

把此例PE改为-10倍，估值观察变为不适用、覆盖率80%、综合为空。把增长改为缺失，则基本面与安全度同时缺失、覆盖率60%、综合为空。这些状态不会转换成低分，也不会进入综合排名。

验证入口：`python -m pytest tests/test_scoring.py -q`。测试覆盖边界值、亏损PE、缺失、无效数字、资金同比缩放、零增长、同分稳定性和每个技术组件的贡献。
