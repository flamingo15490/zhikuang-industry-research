# 欢迎页与新手教程

首页默认进入“欢迎”，以自然语言说明公司研究、利润分析、五维评分及依据、情景矩阵、术语速查和自由问答。原先的架构宣传区不再出现在首屏。

“带我试一次”进入十二步教程：选择公司、主营业务、利润桥、评分快览、评分依据、情景矩阵、术语速查、完整研报总览、技术面、资金面、风险、自由提问。教程可前进、后退、退出，结束后可从欢迎页重新开始；“直接进入平台”进入正常研报工作区。

研报总览及五个正文部分都有可展开的阅读说明，欢迎页也提供相同内容的目录；教程对应步骤可以展开详细讲解。内容包括雷达图与排名、主营构成、宏观周期、财报利润桥、分部毛利、已披露单位经济性、经营情景利润图和双因素敏感性热力图，并解释技术指标、资金比例及风险指标。说明采用读图顺序、读数示例和后续核对问题。技术面、资金面当前主要为文字分析，不宣称提供独立 K 线或资金流向图。

公司示例默认南山铝业，可改为研究池内其他公司。加载入门数据直接调用本地研究上下文，不生成AI正文、不调用付费模型；页面标明“本地数据导览，尚未生成AI研报”。若没有合格本地记录，显示错误并保留当前步骤。主营分部不可比时不硬凑占比图。

未加载公司不能进入业务讲解；未查看评分不能进入计分依据；矩阵计算完成（包括明确缺项说明）后再继续。术语步骤自动展开搜索；最后只展示问答入口，不自动发送示例问题。数据仍保留原有财务期间及行情日期，教程不刷新数据。

引导为页面内提示，不遮挡工具。业务与利润步骤暂时隐藏无关的研报总览，退出恢复完整页面；图表在从隐藏状态展开或视口变化时同步尺寸。

验证入口：`python -m pytest tests/test_onboarding.py tests/test_score_ui.py -q`，以及 `tests/onboarding.browser.js`（真实本地数据，桌面1280/手机390，十二步、分区讲解展开、错误输入、退出、重启及跳过）。

2026-09-08 验证结果：全量 Python 测试 341 项通过；桌面与手机端八步教程通过，包括错误输入、上一步、退出、重新开始和直接进入平台；七家公司及七类经营模型的利润图表回归通过；主营构成、宏观周期状态的问号说明在两种视口下均通过悬停、点击固定及关闭检查。
