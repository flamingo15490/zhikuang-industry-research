# 有色金属投研 Agent 项目说明

更新日期：2026-09-06。本文描述当前已实现能力和使用边界；演示、评测、复现与提交状态以对应产物及执行计划为准。

## 目标用户与任务

目标用户是中小投研团队的有色行业研究员。产品辅助三类任务：从财报核对利润来源、比较公司分部与经营环节、检查商品价格或经营参数变化的财务含义。研究员仍负责确认披露范围、假设和结论；产品不执行交易，也不代替投资决策。

客户需求与付费意愿仍需真实使用者验证，开发者演示不等于客户反馈。研究池目前有140家公司缓存，不据此宣称每家公司所有经营参数均齐全。

## 技术结构

| 层 | 主要位置 | 职责 |
|---|---|---|
| 交互与研究流程 | `webui.py`、`agent.py`、`report.py` | 接收问题、调用工具、组织研究输出 |
| 确定性金融计算 | `tools/profit_analysis.py`、`tools/profit_scenarios.py`、`tools/sensitivity_core.py` | 报表勾稽、经营情景、同期间收入冲击 |
| 展示与证据 | `profit_ui.py`、`profit_charts.py` | 利润桥、分部表、情景图和来源状态 |
| 五维观察 | `scoring.py`、`score_data.py`、`score_view.py`、`score_ui.py` | 版本化规则、采集校验、同批比较与原始指标 |
| 数据 | `data/` | 原始缓存、完整利润表及其他行情和研究输入 |

LLM负责工具选择和文字组织；确定性工具提供可核对数值，但模型仍可能漏调用或在文字中算错。工具参数化支持研究池内查询，但数据缺失和不适用情形会限制可计算范围，不能由参数化接口推出“任意问题均能回答”。

当前注册15个工具：宏观状态、股票基本面、财务指标、板块列表、公司画像、价格敏感性、实时股票行情、金属行情、技术指标、资金流、风险扫描、板块冲击矩阵、行业电解铝参考、公司利润分析、经营情景计算。注册表为 `tools/__init__.py`。

## 三类金融结果

### 财报实绩与会计推导

公司利润桥选取已公告的同报告期报表，从营业收入扣营业成本得到毛利，再展开费用和其他损益，核验利润总额、净利润与归母净利润。未分类损益用明确残差表示；没有明细不填零。亏损、税收抵扣、少数股东亏损与异常差额保留符号。

默认选择财报与产品/行业分部的最新共同报告期；用户可以主动选其他期间，分部不匹配时单独提示。产品和行业不能重复累加；分部缺成本时不推算毛利。只有收入、成本和毛利都可与合并报表勾稽且层级清楚时才展示分部贡献率。

### 经营情景假设

提供7个独立模型：矿山采选、外购精矿TC/RC冶炼、电解铝、金属加工及功能材料、化合物及分离加工、再生回收、贸易及供应链。各模型明确币种、吨矿/吨金属/吨成品等单位、品位和回收率要求。

模型终点是输入成本范围内的假设经营利润或贡献。缺少同口径销量、税费、少数股东及其他必要参数时不转换成公司归母净利润。电解铝经验单耗等只作行业假设；南山铝业等加工业务不因名称含“铝”就套用整家公司电解铝利润。泛称“冶炼”也不能证明外购精矿TC/RC业务。

### 收入冲击近似

单股与板块共享 `analyze_sensitivity` 规则：

`收入变化近似 = 同报告期明确识别的独立分部收入 × 实现售价变化百分比 / 100`

假设报告期销量固定，相关产品实现售价按输入金属价格冲击同比例变化。这是用户选择的情景条件，不是已经验证的商品价格传导关系。结果只覆盖明确标签，不将未识别业务视为零暴露。

默认不使用合并金属均分、粗披露或未知占比。收入必须与同期间分部范围勾稽，矩阵按报告期分组，不直接比较中报与年报金额。加工、贸易等企业的成本与售价联动未测算，不能称为利润影响排名。

若归母净利润为正，可以展示“收入变化额/正归母净利润”的量级比值；它不是净利润变化率。净利润为零、为负或缺失时不显示该比值。以营收100亿元、明确分部50%、实现售价变化1%为例，收入变化近似0.5亿元；除以10亿元正净利润得到5%，不是500%。

## 五维评分体系

五维均完整时等权各20%；缺项和不适用均保留为空，不参与综合排名。个股、均值与排名使用同批次及财务期间，市场相关维度还要求实际行情日期一致。均值至少3个有效样本，综合排名至少3家完整可比公司，同分并列。

| 维度 | 评判依据 | 关键边界 |
|---|---|---|
| 基本面 | ROE分档70% + 归母净利润同比增长分档30% | 上年同期利润非正，不强行算增长 |
| 估值观察 | 正PE(TTM)分档 | 非正PE不适用；低PE不等于周期行业便宜 |
| 技术面 | 50分基准，均线、MACD、RSI、20日收益加减 | 前复权日K，日期与样本长度不足则缺失 |
| 资金面 | 同五日净流入/成交额，50+4×百分比，限制在10至90分 | 两端单位与五个交易日均须校验 |
| 安全度 | 资产负债率40% + 增长30% + 流动比率30% | 不混入披露质量扣分，不是信用评级 |

具体阈值、零值和边界例子见 [五维评分规则](五维评分规则.md)。增长重复出现，合计占综合分12%，不能把五维称为互相独立。规则尚未经收益预测或样本外回测验证。

2026-09-06发布批次含140家公司，61家五维完整；财务期间2025-12-31，完整公司的实际行情日期2026-09-04。其他公司保留接口失败、基期不适用及财务核验缺项。快照原始值可重放；当前前复权历史不能冒称严格历史点时复原。

## 来源与验证边界

- 完整利润表独立保存在 `data/profit_analysis/`，保留源请求链接和抓取时间；旧年报缓存作为明确标注的回退。
- 已知财报公告日用于过滤未来披露。部分主营构成缺公告日和原公告链接，历史点时性尚未全链路完成。
- 在线行情是请求时快照，不能伪装成历史可获得数据；第三方接口可能超时、过期或缺失。
- 历史敏感性研究使用最新业务占比近似，属于样本内结果。25%/4%斜率已退出当前模型，净利率分组不能作为采矿/冶炼经营分类。
- 历史电解铝价差与毛利率相关性只说明样本共变，不能证明因果、样本外预测能力或整家公司利润适用性。
- 工具输出和确定性测试并不保证LLM每句文字都正确。证据覆盖、任务评测和客户节时效果必须引用实际产物，未测得的不写成已实现效果。
- 当前导出证据覆盖已映射的财报披露字段、毛利及分部和部分单位经济性推导。未分类损益残差与勾稽差异尚未全部建立输入证据链，不能声称利润桥每个金额均已完成独立证据化；LLM引用编号也不等于其文字金额已自动核验。

## 运行与交付

使用 `python webui.py --port 7860` 启动研究界面；CLI为 `python main.py "问题"`。本地LLM配置来自 `.env`，依赖和数据准备见项目README。没有LLM配置时，基于本地缓存的确定性财务和情景工具仍可直接调用。

验证命令为 `python -m pytest -q` 和 `python scripts/audit_profit_analysis.py`。收入冲击离线扫描产物是 `output/evaluation/sensitivity_coverage.csv`，当前2520条公司×金属记录中81家公司至少有一种可计算收入近似，不能把这一数字称为利润预测覆盖率。

提交前还需完成并核对真实任务评测、运行环境复现、客户场景材料和演示附件。公开数据商业授权、团队身份与提交范围需单独确认，不随代码实现自动成立。
