## 最小依赖

利润页面通过 `data/company_profile_summary.parquet` 解析名称和代码；读取对应 `data/profit_analysis/profit_*.parquet` 与 `data/company_profile/zy_*.parquet` 生成利润桥和分部比较。经营披露页读取 `operating_metrics.json`，并保留 `operating_sources.json` 说明已查范围及限制。私有包还保留这三家公司已有年度简表作为原有回退来源。

包内仅保留三行名称索引及这三家公司对应数据，不依赖140行全量画像。敏感性模块运行时导入 `scripts/build_company_profile.py` 的标签解析函数，因此该脚本属于必要源码。网络数据采集脚本和本机硬编码路径脚本不作为最小启动依赖打包。

合成包公司名称为“合成样例-矿山”“合成样例-加工”“合成样例-缺失”，代码不代表真实证券。数据含显式synthetic标志，来源URL留空；不伪造公告来源和经营披露核验记录。固定手工数字仅用于软件行为核验，不能证明模型对真实公司研究有效，也不能计入真实经营数据覆盖率。

## 安装与离线启动

解压后优先阅读 `PACKAGE_README.md`。使用Python 3.12及独立虚拟环境。存在锁文件时执行：

```powershell
python -m pip install -r requirements-lock.txt
python offline_demo.py --smoke
python offline_demo.py --port 7860
```

若候选包尚未附带锁文件，则暂用 `requirements.txt`，并以manifest的 `has_requirements_lock` 判断是否完成依赖冻结。启动地址为 `http://127.0.0.1:7860`。离线入口复用原 `profit_ui.py` 组件，选择公司后加载；入口不会发起LLM、实时行情或数据刷新请求。端口占用时指定其他端口。

完整 `webui.py` 与命令行仍保留，但其研报、问答需要用户自行配置模型API，宏观和实时行情等功能可能需要额外合法数据或联网条件。不应把这些缺少数据的功能称为已在最小包中完整复现。

安装 `requirements-test.txt` 后可先运行包内不依赖真实全量缓存的计算和评分器测试。完整原项目测试和原30题实测复现需要完整冻结资料，本包未再分发它们。

## 数据许可

公开网页或数据接口可访问，不等于获得商业使用、再分发或模型训练授权。真实本地缓存涉及第三方聚合接口、公告文本及由其提取的数据。现阶段只记录来源，不宣称已经完成授权核实。商业化前应逐项确认接口条款、公告材料使用边界、组织内部再分发、缓存保存及终端展示条件。

私有包保留必要来源URL和提取限制；不包含原公告PDF或完整公告文本。已提取售价和成本经公告文本核对，但PDF版式视觉核验未完成。部分分部数据缺公告日及原链接，不承诺全链路历史点时性。源代码的著作权归属和第三方依赖许可证也应由提交人确认；构建脚本不自动授予任何许可证。

## 清单与检查

`MANIFEST.json` 逐文件记录相对路径、字节数和SHA256，外部同名manifest还记录ZIP哈希及解压后的检查结果。`SCAN.json` 检查白名单文件、解码后的Parquet文本、高置信度密钥模式及个人目录绝对路径；报告只含文件路径和问题类型，不显示匹配内容。

打包排除 `.env`、认证信息、日志、虚拟环境、备份、原公告PDF、全量缓存及原始API日志。安全 `.env.example` 由脚本生成，密钥为空。数据中的个人目录路径移除，来源网络地址保留。有限规则扫描不构成绝对安全保证或法律审核；正式提交前仍应人工检查最终清单和公开范围。

构建命令为 `python scripts/build_submission_package.py --kind both`。默认对两个ZIP分别解压到临时目录，移除验证进程的模型密钥环境变量，构建真实Gradio利润组件并核查三家公司报告期、利润桥和缺失状态；再在空闲本地端口启动服务并读取配置接口，检查后关闭服务。检查通过表明当前解释器及依赖下的离线组件与HTTP服务可用，不代表已做包内浏览器视觉验收；干净虚拟环境验证应单独记录，不能由这一步替代。
