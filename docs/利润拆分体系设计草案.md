# 利润拆分体系设计草案

状态：用户已确认，已实现并进入最终验证。完整利润表先行补采，公开经营参数另行保留来源与口径。

## 目标与范围

将估值页目前的单一电解铝瀑布图扩展为适用于有色金属研究池的利润分析体系。
按企业实际经营环节选择模型，兼容多业务综合企业；财报实绩与情景假设分开显示。
复用现有 Python、Gradio、Plotly 与本地财报缓存，不引入新的前端框架。

## 已核实的现状

- `report.py::_is_aluminum` 只判断有无铝收入，不能判断企业是否以电解铝生产为主。
- `tools/_resolve.py::classify_business` 用历史净利率划分敏感性校准样本，不适合充当经营环节分类器。
- 140 家企业有利润表与主营构成缓存；最新利润表的六个核心桥接字段完整的有 113 家。
- 最新产品分类至少有一条成本记录的有 134 家，全部产品行有成本记录的有 125 家。这不等于通过财务一致性与合并口径验证。
- 最新产品行中，615 条完整记录的收入减成本与利润在收入万分之一容差内一致，2 条不一致。
- 已抽查紫金矿业、南山铝业、北方稀土：利润表最新为 2025 年报，分部最新为 2026 中报。
- 紫金矿业、北方稀土最新部分分部只有收入，没有成本，不能按收入权重推定分部利润。
- 缓存中没有覆盖全研究池的产销量、单位采选成本、TC/RC、加工费、回收率等经营参数。

## 方案选择

推荐采用三层体系：通用财报利润桥、真实分部毛利拆分、分类经营情景模型。

另外两种方案的局限：只增加若干行业吨利润模板仍无法处理多业务企业及缺失参数；只做财报瀑布图虽然可靠，但不能解释不同产业环节的利润驱动因素。

## 第一层：公司财报利润桥

以同一报告期、同一合并口径的报表为依据：

营业收入 - 营业成本 = 毛利

毛利 + 费用及其他损益净额 = 利润总额

利润总额 - 所得税 = 净利润

净利润 - 少数股东损益 = 归母净利润

当前缓存没有销售、管理、研发、财务费用及投资收益明细。
因此“费用及其他损益净额”只能按利润总额减毛利计算，并标注为报表差额推导，不能命名为“期间费用”。
后续补充完整利润表字段后才展开其明细，不凭空拆分。

图表：横向利润瀑布图，以亿元为单位；增减项目按正负着色，总计独立着色。
负毛利、负所得税、少数股东亏损和归母亏损都保留原始符号。
悬停显示报表项目、金额、报告期、公告日与来源；同页提供原始数值表。

缺失字段不填零。能展示毛利桥时展示局部桥并注明终点；无法核验的终点不绘制成已确认总计。
报表加总不一致时显示差异及数据状态，禁止偷偷合并到费用中。

## 第二层：分部毛利贡献

单个分部毛利 = 该分部披露收入 - 该分部披露成本。

- 优先采用产品维度；产品维度不可用时采用行业维度，禁止将产品、行业、地区重复累加。
- 保留业务原名和原始数据，不使用金属收入权重推定毛利。
- 识别“其中”子项、总计、内部交易抵销，采用同一层级。
- 合并标签保持合并，不能将“铜钴产品”毛利对半分配。
- 无法确认层级或存在内部交易时，只比较已披露分部，不宣称贡献加总为公司毛利。
- 缺成本的分部展示收入与“毛利未披露”；收入减成本与披露利润不一致时列为异常，不纳入毛利贡献加总。
- 分部与公司桥默认选共同报告期；没有共同期时独立标注各自期间，禁用跨期贡献率及合并加总。

图表：横向分部毛利条形图，允许负值；旁边列收入、成本、毛利率的明细表。
只在分部与公司期间及合并范围一致、总额可核验时显示贡献率。
亏损或接近零的总毛利不做饼图，以免产生误导性的占比。

典型呈现：

- 南山铝业：冷轧卷板、氧化铝粉、铝型材、铝箔等分部的实绩毛利，不套整家公司电解铝成本。
- 天齐锂业：锂矿与锂化合物及衍生品分别展示，避免当作纯锂盐加工企业。
- 江西铜业：阴极铜、铜杆线、铜加工、贵金属、硫酸等业务贡献，区分产品分类与经营环节判断。
- 贵研铂业：再生资源、新材料与供给服务分别呈现。
- 紫金矿业、北方稀土：仅有收入的分部如实显示缺失，不画虚构毛利。

## 第三层：按经营环节的情景模型

产品与金属分类描述“生产什么”，经营类型描述“如何盈利”。
优先以明确的主营披露证据识别经营类型，允许一家公司对应多个环节。
“阴极铜”“黄金”“铝”等产品名不能单独证明自产矿或冶炼方式；低置信度时要求选择情景类型，不自动下结论。
人工核验的映射须记录来源和适用报告期；不得复用净利率阈值作为经营分类证据。

| 经营类型 | 模型终点与公式 | 关键输入 | 适用范围 |
| --- | --- | --- | --- |
| 矿山采选 | 单位经营利润 = 实现售价 - 同口径单位采选成本 - 运输销售成本 - 资源税费 + 未含在成本中的副产品抵扣 | 实现价格、销量及单位、成本范围、税费计价基数 | 金银铜铅锌锡及小金属矿山 |
| 外购精矿冶炼 | 单位冶炼经营利润 = 同单位折算的 TC/RC 收入 + 副产品净收益 - 冶炼转换成本 | 精矿品位、干湿基、计价金属与回收率、TC/RC 单位、汇率、转换成本 | 铜铅锌等外购精矿冶炼 |
| 电解铝 | 吨铝经营利润近似 = 铝价 - 氧化铝消耗成本 - 电力成本 - 阳极辅料及已纳入的其他成本 | 氧化铝价、电价、单耗、成本边界 | 电解铝生产业务；保留现有参数与来源说明 |
| 金属加工及功能材料 | 单位加工贡献 = 实现加工费或单位售价与原料价差 - 单位转换成本 - 损耗成本 | 定价模式、加工费、原料计价基础、成材率、转换成本 | 铜杆线、铝板带箔、钛材、磁材、合金及其他深加工 |
| 化合物与分离加工 | 单位产品经营利润 = 产品实现售价 + 副产品净收益 - 单位原料消耗量×原料成本 - 转换成本 | 产品纯度、原料品位、回收率、外购或自产口径 | 锂盐、稀土分离、镍钴盐等 |
| 再生回收 | 单位处理利润 = 可回收产品销售额 + 处理服务费 - 废料采购成本 - 分选冶炼成本 - 环保处置成本 | 原料计量单位、品位、回收率、可回收产品价格、处理成本 | 再生铜铝、贵金属循环利用等 |
| 贸易与供应链 | 交易贡献 = 销售收入 - 采购成本 - 物流仓储 - 融资及套保相关净成本 | 购销同口径金额、周转天数、资金成本 | 金属贸易、供给服务 |
| 综合一体化 | 分业务分别计算；仅在期间、币种与单位对齐且有内部抵销依据时汇总 | 分部销量与口径、内部交易抵销、公共费用分摊依据 | 多金属、多环节及上下游一体化企业 |

上述模型终点为对应口径的经营利润或贡献，不能直接称作公司归母净利润。
AISC 与现金成本分别处理；成本已包含副产品抵扣、维持性资本开支等项目时禁止重复扣减。
原料按“吨矿”计价而产成品按“吨金属”计价时，必须显式输入品位及回收率完成单位换算。
缺少换算参数时禁止计算。跨产品、跨币种、含税与不含税口径不直接相减。

图表与交互：

1. 情景输入区按当前经营模型展示数值输入、单位与来源状态；有数据的自动载入，无数据的留空待输入。
2. 输入齐全后显示单位利润瀑布图，标明“假设测算”及全部参数。不得悄悄填充行业成本常数。
3. 用二维热力图展示主要两项驱动因素的组合：如矿山售价×成本、冶炼 TC/RC×转换成本、加工费×转换成本；在范围内标注盈亏平衡线。
4. 支持恢复原始输入；无可靠基准时不输出“当前行业利润”或“当前历史分位”。
5. 输入缺失时保留计算公式、所需字段与数据状态，完整财报图仍可使用。

## 估值页布局

保留估值正文和现有交互风格，新增统一的“利润拆分”分析区：

- 顶部：公司名、报告期选择、已识别经营环节、数据状态。
- 内部页签：财报利润桥 / 分部毛利 / 经营情景。
- 每次只显示当前页签图表，避免一屏堆叠过多瀑布图。
- 大屏图表与参数区分列；窄屏顺序堆叠，图表使用横向标签并允许必要的换行。
- 财报实绩和假设测算有明确标记；不同单位的图不共用坐标轴。

## 接入位置

- 新增利润分析工具模块：财报取数与校验、分部取数、经营类型与结构化模型输出。
- 新增情景计算模块：纯函数公式与单位校验，不依赖 LLM。
- 图表模块复用 Plotly，数值统一来自结构化模型，禁止在图表中重复实现财务计算。
- `report.py` 使用适用模型摘要替代无条件提供电解铝模型；保留估值指标与现有价格敏感性。
- `webui.py` 接入页签、报告期选择、参数输入、图表和缺失状态；保持现有研报流式输出及排名交互。
- `tools/__init__.py` 注册统一利润分析工具，使自由问答可访问同一数据与结论。

## 验收

- 南山铝业、华峰铝业不再默认展示整家公司电解铝利润。
- 矿山、冶炼、加工、锂盐、稀土、再生及综合企业均有适用的图表或明确的数据不足状态。
- 财报桥加总可核验，负数、零利润、缺失字段、异常报表均有测试。
- 分部测试覆盖重复层级、合并标签、内部抵销、缺成本和期间不一致。
- 情景模型测试覆盖盈亏平衡、价格/成本方向、单位换算、零回收率和参数缺失。
- 对全部 140 家企业做离线覆盖扫描；不能计算的逐项记录原因，不能用默认值填满覆盖率。
- 浏览器验证切换公司、报告期及模型后无旧数据残留；在桌面与窄屏检查图表、输入和悬停。
- 现有排名悬停回归测试继续通过。
